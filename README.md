# RFM Customer Segmentation Analysis

## Project Overview
RFM (Recency, Frequency, Monetary) analysis on 541K+ 
transactions from a UK-based e-commerce retailer 
with 4,339 unique customers.

## Key Findings
- Identified customer segments: Champions, Loyal, 
  At Risk, Lost and New Customers
- Champions contribute the highest revenue
- At-Risk segment needs immediate retention action

## Tools Used
- Python (Pandas, Seaborn, Matplotlib)
- Excel (RFM Datasheet and KPIs)
- Power BI (Segmentation Dashboard)

## Dataset
UCI ML Repository: Online Retail Dataset
541K+ transactions | 4,339 unique customers
